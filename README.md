# Summarycheck: Advanced Text Alignment & Heat-Map Comparison

A sophisticated analytical tool designed for high-resolution comparison and structural validation of text documents, specializing in structured vs. unstructured data alignment.

## Features
- **Global-First Alignment Heuristics:** Derived from Longest Common Subsequence (LCS) logic for superior precision.
- **Structural Audit Dashboard:** Quantitative confidence scoring with real-time discrepancy detection.
- **Multi-Theme Chromatic UI:** Terminal-inspired design with Matrix/Solarized/High-Contrast modes.
- **Dynamic Granularity:** Supports sentence-level precision anchoring and paragraph mapping.
- **Zero-Dependency Architecture:** Lightweight, self-contained HTML/CSS/JS engine.

## Usage
1. Load your primary source text in the first container.
2. Load your secondary text for comparison in the second container.
3. Use the integrated dashboard to navigate alignments and investigate structural orphans.
